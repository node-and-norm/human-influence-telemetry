# Paper Workspace

The [research strengthening workbench](../research/strengthening/README.md) supplies a supplementary claim audit, targeted literature comparison, adversarial results, and prospective usefulness and external-review materials. These additions retain the historical manuscript and published audit boundaries. Consult the [claim audit](../research/strengthening/claim-audit.md) before reusing historical findings as current-contract claims.

This directory contains a working research-paper package. It is not a submitted or accepted paper.

The claim crosswalk controls manuscript assertions. The literature matrix and search log distinguish reviewed sources from planned searches. The novelty audit limits contribution claims. References contain only sources named in the current draft. Submission notes preserve unresolved work.

Run `python scripts/run_research_integrity_audit.py --check` before using a generated claim-gate figure or promoting a mapped claim into the conclusion.
